# 学习路线与验收标准

本路线与书中的“文本处理 -> 注意力 -> GPT 架构 -> 预训练 -> 分类微调 -> 指令微调”主线一致，并在最前面补充训练工程基础。

## 使用规则

每个阶段都要留下四类证据：

- `explanation`：能用自己的话说明原理；
- `implementation`：不复制答案的核心实现；
- `tests`：形状、数值或行为测试；
- `experiment`：配置、曲线、结论和下一步。

上一阶段的门禁未通过时，不把“继续看书”当作主要任务。

## 00 - 训练工程基础

目标：掌握一套与模型类型无关的最小训练闭环。

产出：

- 训练集/验证集拆分；
- 明确的前向、损失、反向和更新代码；
- 终端进度、CSV 与 TensorBoard 日志；
- `last.pt`、`best.pt` 和断点续训；
- 配置快照与四个基础测试。

门禁：

- 能把一个 batch 拟合到接近 100% 准确率；
- 能从 `last.pt` 恢复模型与优化器；
- 能根据 train/validation 曲线识别欠拟合、过拟合和数值异常；
- `ruff` 和 `pytest` 均通过。

## 01 - 理解大语言模型

产出：一页概念图，解释 Transformer、GPT、预训练、分类微调和指令微调的关系。

门禁：不用术语堆砌，向没有背景的人讲清“下一词预测为什么可以产生通用能力”。

## 02 - 处理文本数据

产出：

- 简单 tokenizer 与 BPE 学习笔记；
- `encode`/`decode` 往返测试；
- 滑动窗口数据集和 DataLoader；
- batch 的输入/目标错一位示意与形状测试。

门禁：给定一段文本，能独立写出 next-token 数据批次，并解释每个维度。

## 03 - 编码注意力机制

产出：

- 手算一个三词元自注意力示例；
- 单头自注意力、因果掩码、多头注意力；
- mask、dropout 和输出形状测试；
- 与 PyTorch 参考计算的数值对齐测试。

门禁：能从矩阵维度推导 `QK^T / sqrt(d_k)`、mask、softmax 和 `AV`。

## 04 - 从头实现 GPT

产出：LayerNorm、GELU、前馈层、残差连接、Transformer Block 和完整 GPT。

门禁：

- 逐层形状测试通过；
- 能计算参数量及主要显存来源；
- 固定随机种子时前向输出可复现。

## 05 - 在无标签数据上预训练

产出：

- 训练/验证 loss；
- 逐步完善的生成函数；
- 小型预训练实验；
- checkpoint、resume、最佳模型与样本生成监控；
- 预训练权重加载记录。

门禁：从配置开始复现实验，并用曲线与样本解释模型学到了什么。

## 06 - 针对分类的微调

产出：分类数据流水线、分类头、loss/accuracy、混淆案例和测试集报告。

门禁：训练集、验证集和测试集职责清晰；最终结论不根据测试集反复调参。

## 07 - 通过微调遵循人类指令

产出：指令模板、数据集与 collate、微调脚本、模型回复文件和人工误差分类。

门禁：能够追踪一条原始样本如何变成 token、label、loss，再变成最终回复。

## 阶段完成定义

满足下列条件才把阶段标为完成：

- 代码通过测试与静态检查；
- README 或笔记能解释核心设计；
- 至少一次实验有配置、指标和结论；
- `git status` 中没有误提交的数据、日志或权重；
- 能闭卷重写核心部分，而不是只会运行已有代码。
