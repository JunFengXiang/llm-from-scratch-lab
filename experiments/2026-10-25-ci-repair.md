## 实际 CPU 训练

调用现有 `llm_from_scratch_lab.train_toy.main`。使用 `configs/toy_mlp.json` 的参数，仅在临时配置中将 device 设为 cpu、output_dir 指向独立临时产物目录：seed 42、1000 样本、80% 训练集、batch 64、2→32→2 ToyMLP、AdamW、学习率 0.01、weight decay 0.0001、梯度裁剪 1.0、20 epochs。

Python 3.11.17 / torch 2.13.0+cpu；设置 CPU intra/inter-op threads 为 1、`torch.use_deterministic_algorithms(True)`，子进程环境 `OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONHASHSEED=42`。每次调用形式如下（`cpu_config.json` 是上述临时配置）：

```bash
python -c 'import torch; torch.set_num_threads(1); torch.set_num_interop_threads(1); torch.use_deterministic_algorithms(True); from llm_from_scratch_lab.train_toy import main; main()' --config cpu_config.json --run-name repeat_a
```

第二次使用新的 run-name `repeat_b`；单 batch 使用 `--run-name overfit --overfit-one-batch`。
